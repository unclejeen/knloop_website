## 隐私政策



本政策说明 knloop（下称「我们」）在你使用 knloop 应用（下称「应用」）和访问 [knloop.com](https://knloop.com)（下称「本站」） 时如何处理与你隐私相关的信息。

### 一句话概括

你的笔记默认只存在你自己的设备上；我们不会读取或上传你的笔记内容。

### 应用如何处理你的数据

- **本地优先**：应用的笔记、附件与配置保存在你本机的文件系统里，以纯 Markdown 等可读文件为主。我们不提供云端存储，也不要求你把内容上传到我们的服务器。
- **无需账号**：应用不要求注册或登录，我们不会因为使用应用而获得你的手机号、邮箱或真实姓名。
- **不采集内容**：我们不会读取、上传或分析你库里的笔记内容，也不会在其中投放广告或用于用户画像。
- **Git 版本记录**：应用会在本地为你的知识库自动提交，提交记录保存在你的设备或你自行配置的远端仓库中。如果你把仓库推送到 GitHub 等第三方平台，数据的处理方式由该平台的政策决定。
- **MCP 与本地 Agent**：应用通过内置的 MCP 服务把笔记提供给本机的 AI Agent 读写，这些读写发生在本机进程之间，不经过我们的服务器。

### 当你连接第三方 Agent 时

如果你在应用里连接 Claude Code、Codex、DeepSeek Harness 等云端 AI Agent，或让其它第三方工具访问你的笔记，你交给这些工具的文本会按其自身的服务条款与隐私政策处理，可能被传输到它们的服务器。这部分不在我们的控制范围内。请在使用前阅读对应服务的隐私政策，并自行判断哪些内容适合交给它们。

### 本站收集的信息

- **没有账号与表单**：本站是静态站点，不提供注册、登录或留言表单，我们不主动向你索取个人信息。
- **站内搜索**：搜索完全在你的浏览器内完成，关键词不会发送到服务器。
- **语言偏好 Cookie**：当你切换中英文时，本站会写入一个名为 `knloop_locale` 的 Cookie，用来记住你的选择，有效期一年。它不含任何个人身份信息。清除浏览器 Cookie 即可重置。
- **主题偏好**：深色 / 浅色主题保存在浏览器的 localStorage 中，仅存在于你的设备上。
- **访问日志**：本站由第三方静态托管服务提供，托管方可能按其标准做法记录访问日志（如 IP 地址、User-Agent、访问时间）用于运维与安全防护。我们不会把这些日志与你的身份关联，也不会用于广告投放。
- **不做追踪**：本站不投放第三方广告，未接入第三方统计分析或行为追踪脚本。

### 下载与外部链接

- 安装包发布在 GitHub Releases，下载行为受 GitHub 的服务条款约束。
- 站点给出的部分下载直链经过 gh-proxy 等公共加速代理，代理方在转发时会看到你的请求信息（如 IP 地址与 User-Agent）。
- 本站会链接到微信群、QQ 群等第三方平台，你在这些平台上的信息由腾讯按其政策处理。

### 我们不会做的事

- 不出售、不出租你的个人信息。
- 不把你的笔记内容用于训练模型。
- 不在应用或本站中嵌入第三方广告或行为追踪 SDK。

### 数据留存与删除

你的笔记由你自己持有：删除设备上的文件即可删除对应数据，我们不保留副本。如果你曾通过第三方 Agent 或 Git 远端提交过内容，需要到对应服务中自行删除。你主动发给我们的反馈信息，我们会保留到问题处理完毕或你要求删除为止。

### 未成年人

本站与应用面向一般用户，不面向未成年人单独提供服务，我们不会主动收集未成年人的个人信息。如果你是未成年人，请在监护人的指导下使用。

### 政策更新

我们可能会更新本政策。发生实质性变更时，我们会更新本页的生效日期，并在站点上以显著方式提示。继续使用应用或本站，即表示你接受更新后的政策。

### 联系我们

如果你对本政策有疑问，或希望行使查阅、更正、删除个人信息的权利，请通过[问题反馈](/feedback)页面提供的微信群或 QQ 群联系我们，我们会尽快回复。
