欢迎使用 knloop

knloop 是一个本地优先的 Markdown 知识库。你写下的所有内容都以纯 Markdown 文件保存在自己的知识库文件夹里——没有锁定、没有专有数据库，文件在任何编辑器中都保持可读。

现在就开始记录你的想法……

试试一些 Markdown：

# 标题
- 列表
> 引用
`行内代码`

笔记就是文件

每篇笔记都是带有 YAML 元信息（frontmatter）的 Markdown 文件：

---
tags: ["note", "Topic"]
related_to: "[[knloop]]"
---

# 示例笔记

  • 第一个一级标题就是笔记标题。knloop 会在笔记列表、搜索和双链中使用它。

  • frontmatter 中的标签用来组织笔记——共享同一标签的两篇笔记彼此相关。

  • 关系是任何包含 [[双链]] 的 frontmatter 属性，例如 related_to、belongs_to 或 has。

  • 文件名使用 snake_case.md，一个文件一篇笔记。

连接你的思考

组织来自链接和标签，而不是文件夹。可以在正文或 frontmatter 中的任何位置使用 [[双链]] 连接笔记：

  • [[笔记标题]] 链接到另一篇笔记

  • [[笔记标题|显示文本]] 使用自定义文本链接

knloop 会递归读取所有文件夹中的笔记，因此可以按自己觉得自然的方式组织知识库——意义存在于链接和属性里，而不在目录树里。

与 AI 代理协作

knloop 为代理协作而构建。代理可以读取、搜索、创建和编辑你的笔记，并遵循 [[AGENTS]] 中描述的同一套约定。请把知识库根目录的 AGENTS.md 保留为人与代理共享的规则手册。

开始使用

  • 读到这里

  • 新建一篇笔记，并给它一个标签

  • 用 [[双链]] 连接两篇笔记

  • 浏览笔记列表与相关笔记

  • 邀请一个代理帮你整理知识库

祝你记录愉快！👋
